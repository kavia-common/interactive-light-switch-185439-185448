# Animated Light Switch Frontend

A lightweight React app showcasing a central animated, accessible LightSwitch component with glow, dynamic shadows, and a responsive floating panel.

## Run

- `npm start` (port 3000)
- `npm test`
- `npm run build`

## Highlights

- Light theme with accents: primary `#3b82f6`, success `#06b6d4`, secondary `#64748b`
- Responsive: centered single-column on mobile, floating card on desktop
- Accessibility: ARIA role="switch", `aria-checked`, keyboard (Space/Enter)
- Smooth animations with subtle ambient gradient and pulsing glow
- No external services or new env vars required
